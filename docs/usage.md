# 使用说明

## 侧栏布局

新版侧栏只有“入口”“便签”两个工具按钮，下方是会员与额度卡片。没有固定的“课程”“工作”按钮；保存的自定义入口在“入口”面板内使用。

## 会员剩余天数

点击会员区域，在设置中填写到期日期。首次使用没有预置个人到期日。

剩余天数按北京时间的自然日计算，不推测具体扣款时刻：到期当天显示“今日到期”，之后显示“已到期”。剩余不超过 3 天时文字使用提醒颜色。续费后需要手动更新日期；本功能不读取账单，也不修改订阅。

## 额度与重置倒计时

额度来自当前客户端内置 CLI 的 app-server。显示的是账号额度，不是上下文窗口、单次对话 token 数或 API 钱包余额。不同账号和客户端返回的数据可能不同；只有接口提供的窗口和时间才可显示。

- 将鼠标移到额度圆环、百分比或额度标签，查看详细信息；键盘聚焦额度区域也可查看。
- 移到会员天数、重置倒计时或其他按钮时，不触发额度详情。
- 倒计时跟随当前圆环对应的额度窗口。已到重置时间但新数据尚未返回时，显示等待刷新。
- 暂时无法读取或数据过期时显示不可用状态，避免把旧数字当作当前额度。
- 额度不超过 50% 时使用提醒色，低于 10% 时使用警示色。

## 快捷入口

点击“入口”添加名称、类型和目标：

- 文件夹：填写本机绝对路径，也可使用 `~/` 开头的路径。
- 网页：填写完整的 `http://` 或 `https://` 地址，使用 Google Chrome 打开。

可编辑或移除已保存入口，最多保存 12 个。添加与打开时会检查目标格式；文件夹必须存在且可访问。不支持将任意命令、脚本、`javascript:` 或 `file:` 地址作为网页入口。

移除入口只删除这条记录，不会删除目标文件夹或网站。

## 临时便签

点击“便签”输入下一步计划。停止输入后自动保存，也可点击“保存”；最多 20,000 个字符。

便签属于本机工具栏数据，不绑定单个聊天，因此切换聊天后仍可查看。没有云同步功能，也不会自动发送给模型或其他人。

多个窗口同时编辑时，过期版本会被拒绝覆盖。界面保留当前草稿，并让你选择读取最新便签，或明确保存自己的草稿。出现“尚未保存”时不要直接关闭客户端，先处理错误并确认保存成功。

## 本地数据与备份

默认程序与数据根目录：

- macOS：`~/Library/Application Support/CodexSidebarTools/`
- Windows：`%LOCALAPPDATA%\CodexSidebarTools\`

个人数据位于安装根目录下的 `data/state.json`。备份时可以复制该文件；其中可能有私人便签、目录或网址，不要上传到公开 Issue 或仓库。不同平台的文件夹路径通常不能直接共用，迁移后需要自行修改。

## 更新与旧版切换

插件自身不自动下载更新。下载新包前核对版本、来源和 SHA-256，备份 `data/state.json`，完整解压后重新运行“安装”；会员日期、便签和快捷入口会保留，不用先卸载。

客户端更新后的加载恢复由后台处理，和下载插件新版本是两件事。后台发现活动窗口缺少本机连接时，会记录一次待办，等你完全退出后自动打开并加载；没有待处理恢复时，普通退出后保持关闭。需要手动触发时使用“恢复插件”入口或 `node manage.cjs recover`。

恢复待办保存在本项目的 `runtime/recovery.json`，不是便签或会员设置。它有期限并限制为本次开机内的恢复，启动前消费待办以避免循环重开。客户端内部界面或协议变化仍可能需要进一步适配。

本项目不会自动卸载或停用旧版插件。建议同一客户端只启用一个版本；遇到冲突先自行决定使用哪个版本，不要同时反复启动多个后台任务。
